# Análisis de influencia de Episios ENSO (Niño 3.4) en el caudal de cuencas de America del Sur– 1950–2019

En este proyecto se analiza la influencia del fenomeno ENOS en los caudales de las principales cuencas de America del Sur por medio de un mapeo de series de tiempo a redes complejas, esto con el fin de cuantificar la influencia del fenomeno ENOS por medio de metricas topológicas de red.

El proyecto utiliza las siguientes librerías de Python:

- pandas
- numpy
- matplotlib
- openpyxl

pip install pandas numpy matplotlib openpyxl
